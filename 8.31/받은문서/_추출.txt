1. 과제 개요
상시 대기형 음성 인터페이스는 사용자가 특정 단어를 말할 때까지 입력을 계속 감시해야 한다. 일반적인 키워드 스포팅 시스템은 마이크 신호를 ADC로 변환한 뒤 디지털 주파수 분석과 분류 연산을 수행하므로, 실제 명령이 없는 시간에도 데이터 획득과 전처리를 위한 전력이 지속적으로 소모된다.
본 과제는 음성의 주파수·시간 특징을 아날로그 회로에서 직접 추출하고, 각 대역의 활성 여부를 1비트로 변환한 뒤, 마이크로프로세서나 FPGA 없이 카운터·디코더·플립플롭·논리 게이트·비교기 등 고정 회로만으로 특정 단어의 시간-주파수 패턴을 판별하는 것을 목표로 한다.
핵심 설계 개념: MM20 마이크의 음성을 PreAMP와 다채널 GIC 필터뱅크에 통과시켜 주파수 성분을 분해하고, 능동 Envelope Detector와 Comparator를 통해 8채널 이진 특징으로 변환한다. 이후 START 시점을 기준으로 네 개의 상대 시각에서 8채널 패턴을 확인하여 사전에 결정된 형판과 일치할 때 WAKE 신호를 발생시킨다. PC는 설계 단계에서 회로 상수를 찾는 데만 사용되며, 완성된 시작품에는 프로그램이 남지 않는다.

3. 전체 회로 구성
신호 흐름: MM20 마이크 → PreAMP → GIC Filter Bank → Envelope Detector → Comparator → CONTROL → WAKE/LED

그림 1. 전체 회로 구성. MM20 마이크, PreAMP, 아날로그용/CONTROL용 1.8 V LDO 2개, 0.9 V 기준전압 생성부, 16채널 확장형 GIC 필터뱅크, Envelope Detector, Comparator, CONTROL 및 WAKE 표시 LED.
현재 전체 스키매틱은 16채널을 모두 배치한 확장형 구조이다. 대회 시작품에서는 16개 GIC/ENV/Comparator 경로 가운데 최종 데이터 분석으로 선택된 8개만 부품을 실장하고, 선택되지 않은 채널은 입력 경로를 포함해 DNP 처리하는 방향으로 진행한다.
4. 아날로그 전단 설계
4.1 MM20 마이크, PreAMP 및 전원 구조
MM20 마이크 출력은 100 nF 커플링 커패시터를 통해 직류 성분을 제거한 뒤 0.9 V에 바이어스한다. OPA379 비반전 증폭기는 90 kΩ/10 kΩ 피드백 저항으로 구성되어 명목 이득이 10 V/V이며, 증폭된 신호를 모든 GIC 채널의 공통 입력으로 공급한다.
외부 3.3 V 전원에서는 두 개의 1.8 V LDO를 사용하여 아날로그부와 CONTROL부 전원을 분리한다. 0.9 V 기준전압은 1.8 V를 100 kΩ/100 kΩ으로 분압한 뒤 OPA379 버퍼와 RC 필터를 거쳐 생성하며, 단전원 아날로그 회로의 가상 기준점으로 사용한다.
4.2 GIC 대역통과 필터뱅크
주파수 특징 추출은 OPA2379 기반 GIC(Generalized Impedance Converter) 능동 대역통과 필터로 수행한다. 동일한 토폴로지에서 채널별 R·C 값을 달리하여 중심주파수를 분산시키므로 ADC나 FFT를 사용하지 않고도 음성의 주파수 정보를 병렬로 분해할 수 있다. 이상적인 GIC 관계는 중심주파수와 Q를 각각 R·C 비로 조절할 수 있어 채널 계획을 회로 소자값으로 직접 매핑하기에 적합하다.

그림 2. OPA2379 기반 GIC 필터 1채널 회로. 동일 구조를 16채널로 배치하고 최종적으로 8채널만 실장한다.

4.3 능동 Envelope Detector
GIC 출력은 음성 주파수로 빠르게 진동하므로, 시간적 지속성을 안정적으로 읽기 위해 OPA4379, BAT54W, 저항 및 커패시터로 구성된 능동 Envelope Detector를 사용한다. 필터 출력의 진폭 정보를 정류·충전하고 설정된 시정수로 감쇠시켜, 해당 주파수 대역의 에너지 존재 여부를 느리게 변화하는 전압으로 변환한다.

그림 5. OPA4379 기반 4채널 능동 Envelope Detector. 동일 블록을 반복하여 전체 채널을 처리한다.

그림 6. 대표 v_env 파형과 970 mV 기준선. Envelope가 문턱을 넘는 시간 구간이 후단 이진 특징으로 변환된다.
4.4 LPV7215 Comparator와 채널별 임계값
각 채널의 Envelope 출력은 LPV7215 비교기로 이진화한다. 현재 기준전압 생성부는 400 kΩ, 5 kΩ 단계 저항, 465 kΩ 및 가변저항으로 구성되어 VTHR094~VTHR100의 약 0.94~1.00 V 기준점을 10 mV 간격으로 제공한다. 최종 8채널에서 어느 기준점을 사용할지는 음성 데이터 분석 후 결정한다.

4.5 아날로그 특징의 이진 시공간 패턴 변환
필터뱅크와 Envelope Detector를 통과한 각 채널의 전압을 시간축으로 배열하면 음성의 주파수-시간 특징이 나타난다. Comparator 문턱을 적용하면 각 시간 구간에서 채널이 켜졌는지 여부만 남는 이진 시공간 패턴을 얻는다. 아래의 “on” 결과는 현재 16채널 시뮬레이션 예시이며, 최종 대상 단어와 사용할 8채널은 아직 확정하지 않는다.

5. MCU·FPGA 없는 디지털 판별부 설계
5.1 기본 구조
Comparator 에서 얻은 이진 신호를 한 번 비교하는 것만으로는 단어의 시간적 순서를 표현할 수 없다. 따라서 CONTROL 부는 START 검출 → 시간 계수 → 네 시각에서의 Template match → 상태 유지 → 최종 WAKE 순서로 동작한다. 판정의 경우 시각별로 쪼개어 진행된다. 1초 구간 전체를 한 번에 비교하지 않고, 발성 시작 시점을 원점(t=0)으로 하는 소수의 시각(state) s에서만 스냅숏을 찍어 비교한다. 시각의 개수는 4를 기준으로 하며, 이 값이 회로 규모를 결정한다.
채널 신호는 CONTROL 부 입구에서 두 갈래로 갈라진다. 한 갈래는 언제 Start 신호를 켜는지 보고, 다른 갈래는 Template 일치 여부를 확인한다.

5.2 START 조건: 발화의 시간 원점
START는 회로 전체를 깨우는 전원 스위치가 아니라 시간 원점 t=0을 만드는 신호다. 아날로그 전단과 START 논리는 계속 동작하고, IDLE 상태에서는 시간 카운터만 멈춰 있다. START를 놓치면 해당 발화는 이후 판정이 불가능하므로, 설계에서는 낮은 오검출보다 높은 START 재현율을 우선하고 그 다음으로 발화 간 START 시점의 지터를 최소화하도록 한다. START detect가 원점을 잡고 RUN latch가 계측 구간을 연다. RUN=1이 되면 Timing counter의 리셋이 풀리고 10 ms마다 1씩 증가한다. 계측 구간은 두 가지 방법으로만 닫힌다. WAKE가 나오거나, timeout 시각에 도달하는 것이다.
timeout은 학습이 정하는 값이며, 마지막 상태 τ(4)보다 크게 잡는다. 그 시각에 Time decode가 DECODE_TO(TimeOut) 를 올리면 RUN latch와 PASS flipflop이 동시에 비동기 CLR되어 회로가 IDLE로 돌아간다. timeout을 짧게 잡을수록 한 번의 오검출이 다음 발성을 가리는 시간이 줄어들지만, τ(4) 직후로 지나치게 붙이면 WAKE 출력 펄스가 짧아지므로 이는 유의해야 한다.
5.3 시각 생성 
Timing counter는 경과 시간을 세기만 하고, 어느 값이 의미 있는지는 모른다. 의미 부여는 Time decode가 한다. 학습이 τ(s)=17을 냈다면 카운터 출력을 읽어 "카운터 == 17"인 순간에만 1이 되도록 하는 것이다. 
5.4 Template Match
각 상태 s는 채널마다 세 값 1, 0, X 중 하나를 갖는 Template M(s,c)를 가진다. 실제 채널 값과 Template의 비교는 그 값이 일치하는 개수를 세고, 그 수가 허용 오차 k(s) 이상이면 MATCH(s)=1로 둔다. 회로에서는 일치 여부 신호들을 같은 크기의 저항으로 묶어 평균 전압을 만들고, 그 전압을 비교기에서 기준전압과 비교한다. 상태 s에서 실제로 보는 채널이 m(s)개일 때
        V_score = VDD × (일치 개수) / m(s),     V_TH(s) = VDD × (k(s) − 0.5) / m(s)
기준전압 V_TH는 상태마다 다르다. X 때문에 분모 m(s)가 상태마다 달라지기 때문이며, 하나의 전압을 공유할 수 없다. 각 상태의 V_TH은 분압 저항 두 개로 만든다.
5.5 PASS 저장, 최종 WAKE 및 timeout
SAMPLE(s)의 상승 edge에서 PASS flipflop이 그 순간의 MATCH(s)를 붙잡는다. 이후 채널 값이 어떻게 변해도 PASS(s)는 유지되므로, 서로 다른 시각에 일어난 네 번의 판정을 같은 시점에 모아 볼 수 있다. 네 PASS를 Final AND로 묶은 것이 WAKE이다. 즉 WAKE는 "네 시각 모두에서 Template과 일치했다"는 뜻이며, 어느 하나라도 어긋나면 출력되지 않는다. WAKE가 발생되면 LED 구동부가 이를 표시한다.

6. 개발 방법 및 검증 계획
6.1 아날로그 회로 시뮬레이션
현재 16채널 확장형 회로를 기준으로 DC, AC Sweep, Transient 순으로 검증한다. 채널별 중심주파수, Q, Peak Gain, Envelope 출력 범위와 Comparator 문턱 대비 여유를 확인하고, 고주파 채널의 이득 저하나 OP Amp GBW 영향을 반영하여 필요한 경우 소자값을 보정한다.
6.2 음성 데이터와 8채널 선정
공개 음성 데이터셋의 대상 단어를 양성(P), 다른 단어·무음·소음을 음성(N)으로 구성한다. 16채널 후보에서 대상/비대상 분리력이 높은 8개 채널을 선택하고, 선택된 채널의 AFE 모델 출력으로 START와 형판 파라미터를 정한다. 현재 “on” 결과는 동작 확인용 예이며 대상 단어 자체도 후보 비교 후 결정할 수 있다.
6.3 연속 오디오 기반 오검출 평가
단일 1초 클립만으로는 시간당 오검출 횟수를 직접 구할 수 없으므로, 비대상 단어를 무작위 간격으로 연결한 연속 오디오 스트림을 만들어 동일한 상태기계를 연속 실행한다. 마지막 통합 검증에서는 발표 환경과 유사한 사람 말소리·기계 소음 조건의 실제 녹음도 추가한다.

10. 기대 성과 및 차별성
ADC 없는 특징 추출: 음성의 주파수 및 시간 특징을 GIC, Envelope Detector, Comparator에서 직접 1비트로 생성한다.
MCU·FPGA 없는 키워드 검출: START, 시간 계수, 형판 비교, 상태 저장을 논리·비교기 회로만으로 구현한다.
데이터가 저항과 배선이 되는 구조: NN에서 얻은 임계값·시각·형판·허용 개수를 프로그램이 아니라 실제 R 값과 배선으로 물리적으로 매핑한다.
16채널 PCB의 선택적 8채널 활용: 기존 설계의 확장성을 유지하면서 대회용 시작품은 필요한 채널만 실장한다.
설명 가능한 판별: 어느 시각에 어떤 주파수 채널이 맞아 WAKE가 발생했는지 Template와 회로도를 1:1로 대응시킬 수 있다.
