# 대역폭 보존 4차 GIC 채널 — 설계 상세 & 트레이드오프

넷리스트: [`../netlists/gic_4th_bw.cir`](../netlists/gic_4th_bw.cir) ·
응답 비교: [`../artifacts/order4_bw.png`](../artifacts/order4_bw.png) ·
설계 스크립트: [`../scripts/design_4th_bw.py`](../scripts/design_4th_bw.py)

배경(왜 이걸 하는가): Phase B에서 실제 2차 GIC 필터가 이상 mel보다 −4.4pp 낮고, 그
원인이 **넓은 스커트의 스펙트럼 블러**(후처리로 복구 불가)임이 확정됐다
([`../../docs/phase_b_summary.md`](../../docs/phase_b_summary.md)). 유일한 물리적 해법은
필터를 **더 날카롭게** 만드는 것 → 4차.

---

## 1. 회로 구조

**4차 = 2차 GIC 밴드패스 2단 캐스케이드.** 스테이지 A 출력(va)이 스테이지 B 입력으로
들어간다. 각 스테이지 내부는 기존과 동일한 2차 GIC(op-amp 2개: U1=주 증폭, U2=GIC 반전).
내부 배선 상세는 [`../../AFE/artifacts/afe_schematic.svg`](../../AFE/artifacts/afe_schematic.svg)의
"GIC filter" 단과 동일.

```
V_in → [GIC 스테이지 A] → va → [GIC 스테이지 B] → v4 → (능동검출기 → 비교기, 기존과 동일)
        2차 BP (opamp×2)         2차 BP (opamp×2)
```

검출기·비교기는 **변경 없음** — 필터 단만 4차로 교체.

## 2. 대역폭 보존의 원리

동일한 2차 2단을 그냥 캐스케이드하면 스커트는 날카로워지지만(±6→±12 dB/oct)
**-3dB 대역이 좁아진다**(315→210 Hz). 이를 되살리려고 **각 스테이지의 Q를 낮춰
(대역을 넓혀)** 캐스케이드 후 대역이 2차 기준과 같아지게 한다.

- Q는 `R1`으로 조절(Q ≈ R1/RA). 기준 2차 R1=53.3k → **캐스케이드 스테이지 R1c=35.1k**.
- `design_4th_bw.py`가 SPICE에서 R1c를 이분법으로 찾아 대역을 정확히 맞춘다.

## 3. 부품값 (ch6, f_c≈1364 Hz 예)

| 부품 | 값 | 역할 |
|---|---|---|
| RA1 = RA2 (스테이지당) | 12.05 kΩ | 코너 주파수 f_c |
| C1 = C2 (스테이지당) | 9.38 nF | f_c |
| **R1c (스테이지당)** | **35.1 kΩ** | 스테이지 Q(낮춤=대역보존). 2차 기준 53.3k |
| R2 = R3 (스테이지당) | 100 kΩ | GIC 피드백 |
| op-amp | OPA379 ×2/스테이지 = **×4/채널** | GIC 능동소자 |

## 4. 성능 (SPICE 실측, ch6)

| 지표 | 2차 (기준) | 4차 (대역보존) |
|---|---:|---:|
| f_c | 1364 Hz | 1364 Hz |
| -3dB 대역 | 294 Hz | **306 Hz** (동일) |
| 스커트 기울기 | 6.6 dB/oct | **13.1 dB/oct** (2배) |
| 통과대역 둥긂 | — | ±10%에서 ~2.7 dB (동기동조, 큰 리플 없음) |

→ **같은 대역 커버, 스커트 2배 → 이웃 채널 겹침(블러) 감소.**

## 5. 전력 트레이드오프 (추정)

op-amp 정지전류 기반 추정. OPA379 = **2.9 µA @ 1.8V = 5.22 µW/opamp**(논문),
LPV7215 비교기 = 0.58 µA @ 1.8V = 1.04 µW.

| 블록 (채널당) | 2차 | 4차 |
|---|---:|---:|
| 필터 op-amp | 2개 = 10.4 µW | **4개 = 20.9 µW** |
| 검출기 op-amp | 1개 = 5.2 µW | 5.2 µW (불변) |
| 비교기 | 1.0 µW | 1.0 µW (불변) |
| **채널 합** | **16.7 µW** | **27.1 µW (+62%)** |
| **16채널** | ~267 µW | ~434 µW (+167 µW) |

- **필터 전력은 정확히 2배**, 검출기·비교기는 불변이라 채널 총합은 **+62%**.
- 추정 범위: op-amp/비교기 정지전류만 반영(바이어스 저항 전류·마이크·MCU 제외).
  참고로 Cerutti는 8필터 AFE를 1초 취득 0.28 mJ로 보고.
- **부품 수도 2배**: 필터 R 5→10개, C 2→4개/채널 → PCB 면적·정합 부담↑.

## 6. 성능 트레이드오프 & 리스크 (정직하게)

- **정확도 이득은 아직 가설**이다. 4차가 블러를 줄이는 건 SPICE로 확인했지만,
  그게 ML 정확도를 실제로 올리는지는 **미검증**(step 2 이후 별도 승인 ML 실험 필요).
- **커버리지 공백 리스크**: 스커트가 좁아진 만큼 16채널 고정 시 **대역 사이 빈틈**이
  생길 수 있다. 블러 감소가 오히려 채널 사이 스펙트럼 정보를 잃게 하면 역효과 → **step 2에서
  16채널 뱅크의 겹침/커버리지를 정량 점검**해야 한다.
- **전력 예산**: +62%는 µW급 AFE에 유의미. "정확도 +? vs 전력 +62%"는 마일스톤
  목표(분류 1회 ≤15 mJ, 저전력)와 직접 상충 → 이득이 확실할 때만 채택.

## 7. 결론 / 다음

대역 보존 4차 채널을 **설계·검증 완료**(스커트 2배, 대역 동일, 전력 +62% 추정).
→ **step 2**: 16채널 4차 뱅크로 확장, 겹침/커버리지 정량 비교(상관 아님, 스펙트럼
보존 지표), 매트릭스 추출. 결과가 유의미하면 그때 태그된 baseline과 ML 비교(별도 승인).
