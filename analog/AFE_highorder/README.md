# AFE_highorder — 고차/고Q GIC 필터 연구 (격리)

Phase B에서 **실제 2차 GIC 필터가 이상 mel보다 ~4.4pp 낮다**(넓은 스커트의 스펙트럼
블러)는 게 확정됐다([`../docs/phase_b_summary.md`](../docs/phase_b_summary.md)). 그 갭은
후처리(데드존·탈상관)로 복구 불가 → **필터 자체를 날카롭게** 만드는 게 유일한 물리적 해법.
이 폴더는 그 연구를 **격리해서** 한다.

## 격리 규칙 (엄수)

- **이 폴더(`AFE_highorder/`) 안에서만** 작업한다.
- `AFE/`, `data/`, `models/`, `train/`, `configs/`, `docs/`(요약 제외)는 **동결** —
  Phase B 결과를 보존한다. 필요한 `AFE/` 스크립트는 **복사**해서 수정.
- **복귀점**: `git checkout phase-b-2ndorder` 로 언제든 Phase B 완료 상태로 돌아감.
- ML 재학습은 여기 **포함 안 함**. 고차 필터가 SPICE에서 유의미하면 그때 **별도 승인**받아
  태그된 baseline(spice+√ 0.80 / mel+√ 0.85)과 비교 학습.

## 목표

2차 GIC(채널당 스커트 ±6 dB/oct)를 **더 선택적으로** 만들어 블러를 줄인다:

1. **고차**: 2차 GIC 2단 캐스케이드 = 4차 밴드패스(스커트 ±12 dB/oct). 채널당 opamp↑(전력↑).
2. **고Q**: 같은 2차라도 Q를 올려 대역 좁힘 (단, 16채널 고정이면 대역 사이 **커버리지 공백** 위험).

## 계획 (단계)

1. **고차 채널 1개 설계·특성화**: 4차 밴드패스 netlist → `.ac`로 스커트 기울기·대역폭 측정,
   2차 대비 선택도 정량화.
2. **블러 지표**: 상관(정확도 프록시 아님, 교훈)이 아니라 **스펙트럼 보존도**로 평가 —
   예: 인접 채널 응답의 겹침 면적, 또는 필터뱅크→역투영 재구성 오차.
3. **16채널 고차 필터뱅크** 설계 + 매트릭스 추출(ML 그리드 257 bin). 커버리지 공백 점검.
4. **비용 정리**: 채널당 opamp/전력 증가분(µW 예산 대비) — 정확도↔전력 트레이드오프.
5. (승인 후) ML 비교: 고차 spice+√ vs 2차 spice+√(0.80) vs mel+√(0.85).

## 구조 (예정)

```
AFE_highorder/

```

## 결론 (ML 검증 완료 — 4차 기각)

대역보존 4차 뱅크(`bank4_matrix.csv`, 인접 겹침 −49% / 커버리지 유지)로 ML 재학습(RTX,
spice+√, 2차와 동일 파이프라인):

- **4차: best ~0.79 (val 0.790, train 0.78)** vs **2차: 0.80 (val 0.82, train 0.82)** → **약간 하락.**
- 즉 **필터를 날카롭게 해도 정확도 안 오름.** 데드존(Phase B B5)에 이어 두 번째로
  "채널 겹침/블러는 −4.4pp의 원인이 아니다"를 확증. 넓은 스커트 꼬리가 유용한 정보를 담아
  좁히면 손해.

**판정: 4차 기각.** 전력·면적 2× + 정확도 하락. 회로-정합 최선은 **2차 spice+√ = 0.80**.
오프셋 마진은 필터가 아니라 **마이크 증폭기**로 해결(정확도와 직교). 남은 물리적 정확도
레버는 필터 날카로움이 아니라 **채널 수↑**(CLAUDE.md 고정 → 상의). 이 폴더의 설계·측정은
보존(태그 `phase-b-2ndorder`가 2차 baseline, 이 폴더가 4차 연구·기각 근거).
