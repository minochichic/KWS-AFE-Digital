# AWG 벤치 — `bd_base` 비교기 임계 전압 (2026-10-29)

마이크 대신 파형 발생기로 GSC 클립을 **프리앰프 출력 노드 `/GIC_0/vin`** 에 직접 넣는
벤치. 이 조건에서 `bd_base` 가 학습한 임계값 16개를 비교기 V− 전압으로 바꾼 결과.

```bash
python -m experiments.awg_thresholds --tag bd_base --mv-per-unit 121.52 --wav <.../left/54aecbd5_nohash_1.wav>
```

| **디지털 1** | **121.52 mV** (프리앰프 출력 노드). arb 와 원본을 최소제곱으로 맞춘 값, 잔차 0.001 mV. 100 mV / (max−min) = 123.0 은 보간 때문에 ~1% 다르다 |

- **범위 안에서 그대로 맞출 수 있는 7채널**: 1, 2, 3, 5, 7, 9, 12 — 벤치에서 모델 패턴과
  대조할 채널.
- **ch0·ch4** 는 이 클립에서 모델 기준으로 한 번도 안 켜지므로 990 에 둬도 대체로 꺼져
  있을 것이다.
- **900 아래가 필요한 6채널**(10, 11, 13, 14, 15 와 경계의 2)은 하드웨어가 모델보다 덜
  켜진다. 패턴보다 비어 있어도 회로 고장이 아니라 임계값을 못 내린 탓이다.
- 이 클립 기준으로 정규화 1.0 ≈ 프리앰프 출력 ~40 mV (마이크 ~4 mV) 이다.
  `threshold_targets_dc_20261029.md` 의 "1.0 = 마이크 0.4 mV" 가정보다 10배 크다 —
  가변저항 범위로는 **~870..1060 mV** 가 필요하다 (입력 레벨에 따라 달라진다).

## 남은 것

- **검출기 상승폭 실측** — f_c 정현파를 같은 노드에 0.2 / 0.5 / 1 / 2 / 4 / 8 mV(피크)로 넣고
  V_Env(가능하면 최댓값과 평균)를 잰다. 위 표에서 10채널이 시뮬 두 점 바깥(1 mV 아래 또는
  4 mV 위)이다. 이 값이 오면 awg_thresholds 가 시뮬 대신 실측 곡선을 쓰게 바꾼다.
- 다른 클립을 쓰면 "디지털 1 = 몇 mV" 가 달라진다 — 그 arb 로 다시 맞춘다
  (`--arb <파일> --wav <원본>`).
