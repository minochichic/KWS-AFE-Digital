# `bd_base` 임계값 → 채널별 비교기 전압, 실측 DC 기준 (2026-10-29)

동료 보드의 무신호 DC 를 채널마다 잰 값(`dc_measured_20261029.csv`)으로, `bd_base` 가
학습한 임계값 16개를 비교기 V− 에 걸 전압으로 바꾼다.

```bash
python -m experiments.board_thresholds --tag bd_base --dc-csv      # 체크포인트가 있는 원격에서
```

## 실측 DC — 시뮬과 다르다

| | 실측 (무신호, mV) | 지금까지 쓴 시뮬 값 |
|---|---|---|
| **V_Env** (검출기 출력 = 비교기 V+) | 평균 **886.7**, 870.6 ~ 894.8, σ 6.6 | 938.10, 전 채널 동일 (`swing_board.md`) |
| V_Filt (필터 출력) | 평균 902.5, σ 2.7 | — |

- V_Env 가 시뮬보다 **평균 51 mV 낮고 채널 간 24 mV 퍼진다.** V_Filt 은 고르므로 퍼짐은
  **검출기 단**에서 생긴다. 가설(미확인): 검출기 op-amp 입력 오프셋 × 검출기 이득(≈10).
- 튀는 값: **ch10·ch14 V_Env ≈ 870.7** (다른 채널보다 ~16 mV 낮음), **ch12 V_Filt 892.4**
  (다른 채널보다 ~10 mV 낮음) — 부품 확인 대상.
- 그래서 **공통 기준점 938.10 을 쓴 이전 환산(`board_thresholds` 정방향 표)은 이 보드에
  맞지 않는다.** 임계값은 채널마다 자기 V_Env 기준으로 잡는다.

## 가정

1. 정규화 1.0 = **마이크 0.4 mV**(설계점, CLAUDE.md §2.2 추정)에서 그 채널의 검출기 스윙.
   학습은 필터뱅크를 채널마다 최대 이득 1 로 맞추므로(peak-norm) 모든 채널을 같은
   이득으로 보지만, 실물은 고역이 약하다 — 그래서 K 를 채널마다 그 채널의 스윙으로 둔다.
2. 스윙은 **시뮬 값**이다 (`swing_board.md`, ngspice). `≤` 채널(0, 3, 4, 12)은 상한.
3. 비교기 오프셋 0.

```
V_thr[ch] = V_Env[ch] (실측) + thr[ch] × 스윙[ch] @ 마이크 0.4 mV
```

## 읽는 법

1. **BOM 설계값(950~990 mV)이면 16채널 중 8개가 설계점 음량에서 켜지지 않는다**
   (ch0, 4, 10~15). DC 가 예상보다 51 mV 낮아 넘어야 할 높이가 그만큼 커졌고, 고역은
   스윙도 작다. 말소리가 설계점보다 크면 일부는 켜지지만 방향은 분명하다.
2. **목표 16개 중 13개가 900 mV 아래**(871~911 mV)라 가변 범위 900~990 mV 의 아래 끝에도
   못 내려간다. 범위를 대략 860~960 mV 로 옮겨야 한다 — 회로 쪽 결정이다.
3. **6채널(⚠️: 2, 10, 11, 13, 14, 15)은 목표가 자기 DC 위 3 mV 이내**라 비교기 오프셋
   (LPV7215, ~3 mV, 칩마다 다름)이 결과를 정한다. DC 를 쟀어도 정밀하게 맞출 수 없다.
4. 맞추는 순서 제안: 위 목표를 출발점으로 가변저항을 놓고, 녹음한 말소리를 틀어 채널별
   **발화율**이 모델의 학습 발화율에 오도록 미세 조정한다. K·오프셋을 몰라도 수렴한다.
