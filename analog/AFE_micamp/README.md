# AFE_micamp — 마이크 프리앰프 (오프셋 마진 확보, 격리)

**목적**: 마이크(~10 mVpp) 뒤에 간단한 이득단을 하나 넣어 신호 레벨을 올린다. 그러면
(a) 검출기 데드존을 넉넉히 넘고, (b) V+ 스윙이 비교기 오프셋(~5 mV)을 크게 상회 →
**HF 채널이 오프셋에 묻히는 문제 해결**. 정확도는 **불변**(global min-max가 이득 소거),
실물이 sim의 0.80을 실제로 달성하게 하는 것.

## 배경 (왜 필터가 아니라 증폭기인가)
- 오프셋 마진과 스펙트럼 블러는 **직교 문제**. 4차 필터(블러)는 ML 검증서 기각(정확도 하락).
- 증폭기는 **마진**만 고침. 싸고(opamp 1개) 헌장(저전력)과 부합.
- 상세: [`../docs/phase_b_summary.md`](../docs/phase_b_summary.md), AFE_highorder 결론.

## 격리 규칙
- 이 폴더 안에서만. `AFE/`, `data/`, `configs/` 등은 동결. 복귀점 태그 `phase-b-2ndorder`.

## 계획
1. **프리앰프 AC 설계**: 단일공급 비반전 이득단, 50–8000 Hz 평탄 이득. **OPA379 GBW(90kHz)가
   HF 이득을 제한**하는지 확인 → 평탄 유지 최대 이득 결정.
2. **마진 검증**: 프리앰프 통과 후 채널별 V+ 스윙이 오프셋을 넘는지(특히 HF), R7/R8 재도출.
3. **노이즈·전력 트레이드오프**: opamp 1개 추가, 노이즈도 증폭(SNR 불변) 명시.
