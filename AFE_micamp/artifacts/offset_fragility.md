# 비교기 오프셋 취약성 — 오프셋-free 학습 모델 (spice+√ 0.80)

학습된 best.pt를 오프셋 vos 주입하며 평가(재학습 없음). vos = 정규화 threshold std ≈ Vos/전역V+스윙.

| vos | 대응 | test acc |
|---:|---|---:|
| 0.000 (이상) | | 0.8016 |
| 0.020 | | 0.6184 |
| 0.035 ← 프리앰프 | | 0.4695 |
| 0.050 | | 0.3619 |
| 0.075 | | 0.2642 |
| 0.100 ← 프리앰프 無 | | 0.2177 |
| 0.150 | | 0.1614 |

## 결론
- **오프셋-free 학습 모델은 오프셋에 처참**: vos=0.02만 줘도 0.80→0.62.
- **프리앰프(0.10→0.035)는 0.22→0.47로 개선하나 0.80엔 한참 못 미침** → 프리앰프만으론 불충분.
- per-clip 주입 평균 = per-device 기대(Fubini) → 기기 모집단 기대 정확도로 유효.

## 진짜 해법
- **오프셋-인지 학습**: comparator_vos>0로 학습해 강건 threshold 습득.
  + **프리앰프**(오프셋 크기↓). 둘 다 필요. 다음 실험: 프리앰프/무 오프셋 레벨에서 재학습→회복 확인.

## 오프셋-인지 학습 결과 (2×2 완성)

`comparator_vos>0`로 **학습**하면 매 배치 새 오프셋이 주입되어 강건한 threshold를 배운다.

| 오프셋 조건 | 오프셋-free 학습 | **오프셋-인지 학습** | 회복 |
|---|---:|---:|---:|
| **vos=0.035** (프리앰프 有) | 0.47 | **0.73** | +26pp |
| **vos=0.10** (프리앰프 無) | 0.22 | **0.63** | +41pp |
| vos=0 (이상) | 0.80 | — | — |

**결론 3가지**
1. **오프셋-인지 학습은 강력하다** (+26~41pp 회복). 오프셋을 무시한 학습은 실물에서 붕괴.
2. **프리앰프 정확도 가치 = +10pp** (0.73 vs 0.63, 학습 조건 동일). opamp 1개(+5 µW,
   아날로그 전력의 2%)로 얻는 값. per-clip min-max에서는 이득이 소거돼 측정 불가였던 수치.
3. **둘 다 필요하다.** 프리앰프만(오프셋-free 학습) → 0.47. 학습만(프리앰프 없이) → 0.63.
   **함께** → 0.73. 그래도 이상(0.80)까지 7pp 남음 → **캘리브레이션**으로 줄일 대상(E1).
