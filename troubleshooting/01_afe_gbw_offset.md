# 문제 1 — AFE의 GBW·오프셋 (고주파가 묻힌다)

## 증상 (우리가 측정한 것)

| 현상 | 측정값 | 출처 |
|---|---|---|
| HF 채널 V+ 스윙이 작다 | ch15(6.8k) **0.5 mV**, ch13–15 0.5–1.4 mV | `AFE_micamp` 마진검증 |
| 비교기 오프셋과 같은 자릿수 | Vos ~5 mV 가정 → 스윙 ≲ 오프셋 | 동일 |
| 검출기 데드존이 주파수 의존 | 250 Hz 5.9 mV → 4 kHz **12.1 mV** | `AFE/artifacts/detector_char.md` |
| 프리앰프 이득 상한 | G≈10에서 8 kHz 처짐 1.7 dB, G=20이면 4.8 dB | `AFE_micamp/artifacts/preamp_ac.md` |
| ML 붕괴 | 오프셋 vos=0.035에서 0.80 → **0.47** | `AFE_micamp/artifacts/offset_fragility.md` |

## 원인 분해 — **서로 다른 세 물리량**

혼동하면 안 되는 세 가지. 각각 레버가 다르다.

| 물리량 | 무엇을 망가뜨리나 | 지배 요인 | 전류로 개선되나 |
|---|---|---|---|
| **GBW** | 필터 f_c droop, 프리앰프 대역, 데드존 | gm/C ∝ Iq | ✅ (거의 비례) |
| **슬루레이트 SR** | 정밀정류 데드존의 **진짜 병목** | I_tail/C_c ∝ Iq | ✅ |
| **오프셋 Vos** | 비교기 판정 자체 | 소자 **부정합**(mismatch) | ❌ **전류와 무관** |

우리가 SPICE로 확인한 관계:

```
데드존  V_dz ≈ 2·V_D · f / GBW        (f에 비례, GBW에 반비례)
```
GBW sweep에서 기울기 −0.84(이론 −1)로 확인. 단 **단극 모델(SR=∞)은 0.31 mV인데 실측
OPA379는 7.3 mV(23배)** → 실제 데드존은 **SR이 지배**한다.

**핵심**: 오프셋은 전류를 더 써도 안 줄어든다. GBW/SR과 **다른 해법**이 필요하다.

## OPA379의 위치

- GBW **90 kHz**, Iq **2.9 µA @1.8 V** → **FoM ≈ 31 kHz/µA**.
- 이 FoM이 곧 "전력을 얼마나 효율적으로 대역폭으로 바꾸는가". 더 좋은 op-amp = 같은 전류로
  더 큰 GBW·SR.
- 8 kHz까지 평탄한 프리앰프 이득이 G≈10에 막히는 이유가 정확히 이것(닫힘루프 BW ≈ GBW/G).

## 방안 A — op-amp 교체 (TLV 등)

**선정 기준** (부품번호보다 이 축으로 고르는 게 맞다):

| 스펙 | 요구 | 이유 |
|---|---|---|
| GBW | **≥ 500 kHz** 희망 (현 90 k) | 프리앰프 G≥20 확보, 데드존 ↓, 필터 f_c droop ↓ |
| **GBW/Iq** | ≥ 100 kHz/µA 희망 (현 31) | µW 예산 유지하며 대역 확보 |
| **SR** | 클수록 (데드존 실질 지배) | 0 교차에서 2·V_D 슬루 시간 |
| Vos | 작을수록 / **zero-drift면 최상** | 비교기·검출기 오프셋 |
| 공급 | 1.8 V 단일, rail-to-rail I/O | 현 아키텍처 |
| Iq | ≤ 5 µA/개 희망 | 채널당 3개 × 16채널 |

> ⚠️ **확인 필요**: TLV 계열(TLV8802, TLV9061, TLV521 등)과 나노파워 대안들의 실제
> GBW/Iq/SR/Vos는 **데이터시트로 확인**해야 한다. 여기 숫자를 지어내지 않는다.
> 위 표를 채우는 것이 다음 작업(아래 실행 계획 참조).

**주의**: GBW를 올리면 Iq도 대개 올라간다. 16채널 × op-amp 3개 = 48개이므로 **개당 +1 µA도
전체 +86 µW**(1.8 V). 반드시 채널 전체 예산으로 환산해 비교할 것.

## 방안 B — 오프셋은 "교정"으로 지운다 (중요)

**핵심 통찰**: 실제 Vos는 **소자마다 고정된 값**(온도로 천천히 드리프트)이지, 매 발화마다
새로 뽑히는 난수가 아니다. 우리 ML 실험은 클립마다 난수를 뽑았는데 —

- 기기 모집단 **평균 정확도**로는 동일하다(Fubini).
- 그러나 **고정 오프셋은 교정으로 제거할 수 있다**. 이게 실전에서 결정적 차이다.

따라서:

1. **생산 시 채널별 R7/R8 트림** — 무음 상태에서 각 채널 비교기가 막 안 켜지는 지점으로
   분압을 맞추면 **정적 Vos가 상쇄**된다. 남는 건 드리프트뿐.
2. **자동 영점(auto-zero) 부팅 루틴** — MCU가 기동 시 각 채널 임계를 스윕해 교정값 저장.
3. **Zero-drift(chopper) 비교기/op-amp** — Vos가 µV급. 전력·초핑 노이즈 대가 검토 필요
   (⚠️ 나노파워 zero-drift 부품 가용성 확인 필요).
4. **히스테리시스** — 오프셋을 없애진 않지만 임계 근처 채터링을 막아 이벤트 폭주 방지.

> 즉 **오프셋 대책 = (교정) + (강건 학습)**. op-amp 교체는 GBW/SR/데드존용이지 Vos용이 아니다.

## 방안 C — 신호를 키운다 (이미 채택)

- **마이크 프리앰프 G≈10** — HF 스윙 0.5→20 mV, 데드존까지 동시 해결. 채택 완료.
- 더 키우려면 **GBW 큰 op-amp**(방안 A)나 **2단 저이득 캐스케이드** 또는
  **HF 프리엠퍼시스**(고역만 부스트, 저역 포화 회피).

## 실행 계획

1. **op-amp 후보 스펙표 작성** — TLV 계열 + 나노파워 대안의 GBW/Iq/SR/Vos/공급을
   데이터시트에서 채우고, **GBW/Iq FoM**과 **16채널 총 전력**으로 순위화.
2. **거동 모델로 사전 검증** — `AFE_highorder/netlists/gic_4th.cir`에서 쓴 방식처럼
   GBW·SR을 파라미터로 갖는 op-amp 모델로 (a) 데드존, (b) 프리앰프 평탄 이득 상한,
   (c) 필터 f_c droop을 sweep → **"GBW를 얼마나 올리면 무엇이 얼마나 좋아지는가" 곡선**.
   (부품 확정 전에 필요 스펙을 역산할 수 있다.)
3. **오프셋 교정 시나리오 정량화** — 정적 Vos + 트림 잔차(예: ±0.5 mV)로 ML 재평가 →
   교정이 0.47을 얼마나 되돌리는지. (문제 2와 직결)
4. 확정되면 실모델(SPICE)로 full-chain 재검증 + R7/R8 재도출.
