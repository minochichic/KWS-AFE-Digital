# spice(2차 GIC)+√ 학습 threshold → 비교기 R7/R8 매핑

**소스**: spice 필터뱅크 + √ 압축으로 학습한 BinaryMatchboxNet의 채널별 학습 threshold
(best.pt, val 0.8195, epoch 39). 이 값들은 **√압축 + global min-max 정규화된 [0,1] 도메인**.

**매핑**: `V+_thr = V_LO + t_k·(V_HI − V_LO)`, `R8 = 1MΩ·V+_thr/1.8`, `R7 = 1MΩ − R8`.
- V_LO=0.9103 V, V_HI=0.9569 V = 실제 GSC에서 측정한 SPICE 검출기 V+의 전역 최소/최대
  (AFE의 `learned_r7r8.py`가 잰 값 재사용). bias 0.9 V, 단일 1.8 V 공급.
- **√ 도메인 정합**: 이번엔 threshold가 √(진폭) 도메인이고 V+도 진폭이라, mel+log 매핑
  ([`../../AFE/artifacts/threshold_learned_r7r8.md`](../../AFE/artifacts/threshold_learned_r7r8.md))의
  log-vs-√ 왜곡이 없다 → **OFF 채널 0개**로 깨끗.

## 해석 / 한계

1. **OFF 0/16** — √ 정합으로 매핑이 일관적(mel+log 대비 개선).
2. **R7/R8 밀집** (486–494k / 506–514k) — V+ 전역 스윙이 25mV뿐이라 채널 간 임계 차이가 미세.
   저항 공차(1%)만으로도 채널 순서가 뒤집힐 수 있어, 실제론 정밀저항/트림 필요.
3. **고역 ch12–15는 V+ 스윙이 5–7.5mV = 오프셋 수준** → 이 매핑이 HF 오프셋 취약성을
   정량 확인. 실현하려면 (a) 검출기 이득↑(R4↓)로 스윙 확대, (b) 앞단 AGC, 또는
   (c) `normalize="none"` 절대임계 재학습 중 하나 필요.
4. **AGC 근사**: 이 낮은 임계들은 per-clip global min-max(=AGC)가 매 발화 스케일을 맞춰줘야
   의미가 있음. 고정 R7/R8만으론 그걸 재현 못 함(정규화 문서 참조:
   [`../../docs/normalization.md`](../../docs/normalization.md)).

**결론**: 숫자 매핑은 됐고 이전보다 깨끗하지만, **하드웨어 실현엔 HF 마진 확보 + AGC/절대임계
결정이 선행**되어야 한다. (Phase B 맥락: [`../../docs/phase_b_summary.md`](../../docs/phase_b_summary.md))
