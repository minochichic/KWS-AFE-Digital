# 제안 — AFE 설계 확정안

이 폴더는 **지금까지의 결론을 한자리에 모은 것**이다. 실제 AFE를 제작하고, 그 AFE가
만드는 스펙트로그램으로 재학습하기 위한 **설계 근거 문서**다.

레포의 나머지는 과정이고, 여기가 결론이다.

---

## 한 문단 요약

16채널 아날로그 필터뱅크가 만드는 **이진 시간-주파수 이미지**로 12-class 키워드
스포팅을 한다. 가장 큰 문제는 **음량**이었다 — 사람마다·거리마다 신호가 몇 배씩 달라지는데
고정 전압 임계로는 이걸 지울 수 없어 정확도를 8pp 깎아먹었다. 해법은 각 채널을 고정
전압이 아니라 **바로 그 순간 16채널 중 최댓값**과 비교하는 것이다. 음량이 분자와 분모에서
약분되므로 **불변성이 구조적으로 얻어지고**, AGC와 달리 **피드백 루프가 없다.**
회로 변경은 다이오드-OR 한 조각뿐이며 전력은 오히려 준다.

### 아날로그

![AFE 시스템](artifacts/afe_xmax_system.svg)

| 블록 | 확정 내용 | 상태 |
|---|---|---|
| 마이크 | Knowles **MM20-33366-000** (−55 dBV, SNR 70.5 dBA) | ✅ 검토 완료 — ⚠️ **0.9 V 공급** (1.8 V 직결 불가) |
| 프리앰프 | **G = 10 필요** | ✅ 데이터시트로 확정 (§ANALOG 6) |
| 필터뱅크 | 2차 GIC ×16, f_c 166–6761 Hz (mel 등간격) | ✅ ngspice 검증, 동료 v15에 반영됨 |
| 검출기 | 정밀정류 + C3, G=4.7, τ=4.7 ms | ✅ 실측 (스윙 예측 47.0 vs 실측 48.0 mV) |
| **임계** | **V_thr,c = α_c·V_max + (1−α_c)·V_ref** | 🔴 **새로 추가할 부분** |
| **비교기** | LPV7215 **채널당 2개** (2비트 온도계) | 🔴 **+17 µW → +2.5pp** |

**추가 부품**: 다이오드 16개 + op-amp 1개 + 정합 다이오드 1개 + **비교기 16개**.
**전력 순증 ≈ −13 µW** (채널별 분압이 1.8 V 전체가 아니라 ~0.1 V 차이에만 걸리게 되어,
비교기를 2배로 늘리고도 총합은 줄어든다).

## 정확도 사다리 — 무엇이 얼마를 먹는가

세 실험 모두 **네트워크 내부는 이진 그대로**이고 입력 경로만 다르다.

| 입력 | test | |
|---|---:|---|
| 64채널 **연속** log-mel | **0.920** | 모델은 문제없음 |
| ↓ | −5.8pp | 프론트엔드 (64→16채널, 실제 필터, √, xmax) |
| 16채널 **연속** | **0.862** | 연속값 16채널 **천장** |
| ↓ | −6.0pp | 2비트 양자화 |
| **16채널 2비트** | **0.802** | ← **현재** (비교기 2개) |
| ↓ | −2.5pp | 1비트로 더 줄이면 |
| 16채널 1비트 | 0.778 | |

세 가지가 확정된다:

1. **모델은 병목이 아니다.** 좋은 입력을 주면 이진 네트워크가 0.920을 낸다.
2. **정규화로는 더 못 올린다.** 연속 16채널 천장이 0.862이고, 실현 불가능한 완벽
   정규화(minmax)조차 0.802다.
3. **비교기 비트 수는 효과가 있다.** 1→2비트가 **+2.5pp를 +17 µW에** 사 온다.
   8.4pp짜리 양자화 손실의 **31%를 회수**했다.

0.802는 **실현 불가능했던 minmax 상한과 같은 값**이다 — 정규화로는 도달할 수 없던
지점에 비트 수로 도달했다.

## 다음에 할 일 (우선순위)

| # | 할 일 | 기대 | 대가 | 상태 |
|---|---|---|---|---|
| 1 | **비교기 3개 (3비트)** | +? (2비트가 +2.5pp였다) | +17 µW 추가 | 미시도, 최우선 |
| 2 | **`.tran` 역검증** | 시뮬↔회로 불일치 확정 | 계산 시간 | 미시도 |
| 3 | 채널 수 16 → 32 | +4.7pp (Cerutti 곡선) | 아날로그 면적·전력 2배 | 검증된 레버 |
| 4 | 실제 AFE 제작 → 재학습 | — | — | 이 문서의 목적 |
| ✅ | ~~채널당 비교기 2개~~ | **+2.5pp 실현** | +17 µW | **완료** |

**1번을 먼저 재본다.** 2비트가 남은 6.0pp 중 2.5pp를 가져왔으니 3비트가 얼마를 더
가져오는지가 다음 질문이고, 대가는 여전히 비교기 16개(+17 µW)뿐이다. 채널을 늘리는 건
GIC+검출기가 통째로 붙으므로 그 뒤다.

> ⚠️ **작은 교란 요인**: 입력이 16→32행이 되면서 conv1이 커져 파라미터가
> 96,524 → 119,052로 늘었다. 이득이 **정보(2비트)** 때문인지 **용량** 때문인지
> 완전히 분리하려면 k=1에 C를 키운 대조군이 필요하다. 다만 C 스윕에서 64가 이미
> 최적이었고 2비트라는 정보 논거가 직접적이라, 대부분은 정보 쪽으로 본다.

**2번**은 지금 남아 있는 유일한 "모르는 것"이다. 우리 시뮬은 필터를 `.ac`로 정확히
가져왔고 검출기의 진폭 응답(√)도 실측으로 검증했지만, **τ 평활과 대신호 포화는 모델에
없다**. 정상 동작 범위에서는 작지만, 확실히 하려면 실제 과도해석으로 이진 이미지를 뽑아
학습된 모델에 넣어보는 수밖에 없다. 자세한 내용은 [ANALOG.md](ANALOG.md) §충실도.
