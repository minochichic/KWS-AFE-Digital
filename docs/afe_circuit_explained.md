# AFE 회로 완전 해설 — 기초부터

이 문서는 우리 AFE 회로(GIC 필터 → 능동 검출기 → 비교기)가 **왜 그렇게 생겼고 어떻게
동작하는지**를 대학 1학년 수준에서 처음부터 설명한다. 모든 숫자는 실제 벤더 모델
(OPA379, BAT54WT1, LPV7215)로 ngspice에서 **직접 측정한 값**이다.

---

## 0. 이 회로가 하는 일 (한 문장)

> **마이크에서 온 소리를 16개 주파수 대역으로 쪼개고, 각 대역이 "지금 소리가 나는지"를
> 0/1로 알려준다.**

비유하자면 **피아노 건반 16개**를 놓고, 각 건반이 울리면 불이 켜지는 장치다. 그 불빛
패턴(16개 × 시간)을 보고 신경망이 "yes"인지 "no"인지 알아맞힌다.

왜 이렇게 할까? 보통은 마이크 소리를 ADC로 잔뜩 샘플링해서 컴퓨터가 FFT를 돌리는데,
**그게 전력을 제일 많이 먹는다.** 그 일을 아날로그 회로가 대신 해주면 전력이 크게 준다.

```
마이크 → [1단: GIC 필터] → [2단: 능동 검출기] → [3단: 비교기] → 0/1
          "어느 음정?"        "얼마나 세게?"        "울렸나?"
```

## 1. 준비운동 — 알아야 할 4가지

### 1-1. 전압 분배 (분압기)

저항 두 개를 직렬로 놓고 양끝에 전압을 걸면, 가운데 전압은 저항 비율대로 나뉜다.

```
 1.8V ──[ R7 ]──┬──[ R8 ]── 0V(GND)
                │
              여기가 V
```

$$V = 1.8 \times \frac{R_8}{R_7 + R_8}$$

R7 = R8이면 정확히 절반인 0.9 V. 우리 회로에서 **비교기의 기준 전압을 만드는 방법**이
바로 이것이다.

### 1-2. 커패시터 = "DC는 막고 AC는 통과"

커패시터는 **변하지 않는 전압(DC)은 못 지나가고, 변하는 신호(AC)만 지나간다.**

- 물이 안 흐르는 고무막이라고 생각하면 된다. 막을 밀면 반대쪽도 밀리지만(AC 통과),
  한쪽으로 계속 밀어도 물이 넘어가진 않는다(DC 차단).
- 그리고 **빠르게 흔들수록 더 잘 통과한다.** (주파수가 높을수록 임피던스가 작다)

### 1-3. op-amp 황금률 2가지

op-amp(연산증폭기)는 삼각형으로 그리는 부품이고, **출력이 자기 입력으로 되돌아오는
(피드백) 회로**에서는 두 가지만 기억하면 거의 다 풀린다.

> **황금률 1**: op-amp는 **+ 입력과 − 입력의 전압이 같아지도록** 출력을 조절한다.
> (이걸 "가상 단락"이라 부른다)
>
> **황금률 2**: op-amp의 두 입력으로는 **전류가 전혀 흐르지 않는다.** (입력 임피던스가 무한대)

이 두 개로 우리 회로의 거의 모든 전압을 손으로 계산할 수 있다.

### 1-4. 왜 0.9 V가 "새로운 0"인가

소리는 **+와 − 양쪽으로 흔들리는 신호**다. 그런데 우리 배터리는 0 V와 1.8 V뿐이라
음수 전압을 만들 수 없다.

그래서 **한가운데인 0.9 V를 "0점"으로 삼는다.** 신호는 0.9 V를 중심으로 위아래로
흔들린다.

```
1.8V ┤                      ← 위쪽 한계
     │      ╭╮  ╭╮
0.9V ┤─────╯──╰──╯──╰─────  ← 새로운 "0" (무음일 때 여기 머무름)
     │
  0V ┤                      ← 아래쪽 한계
```

회로도에서 `VCC09`(0.9 V)가 여기저기 연결된 이유가 이것이다. **"접지"라고 쓰여 있지
않아도, 신호 입장에서는 0.9 V가 기준점**이다.

## 2. 1단: GIC 필터 — 주파수 골라내기

### 2-1. 왜 필터가 필요한가

"yes"와 "no"를 구분하려면 **소리에 어떤 음정 성분이 들어있는지** 알아야 한다.
사람 목소리는 낮은 웅웅거림(모음)부터 높은 쉬익 소리(s, sh 같은 마찰음)까지 섞여 있다.

그래서 **주파수 대역별로 나누는 필터**가 16개 필요하다. 각각 166 Hz, 295 Hz, ...,
6761 Hz를 담당한다.

### 2-2. "공진"이 뭔가 — 그네 비유

특정 주파수만 통과시키려면 **공진(resonance)** 을 쓴다.

> 그네를 밀 때, **그네의 고유 리듬에 맞춰** 밀면 점점 크게 흔들린다. 아무 박자로나
> 밀면 흔들리지 않는다.

전자회로에서 그네 역할을 하는 게 **커패시터(C)와 인덕터(L)의 짝**이다.
- 커패시터: 전기를 **전압** 형태로 저장 (그네의 높이)
- 인덕터: 전기를 **전류** 형태로 저장 (그네의 속도)

둘이 에너지를 주고받으면서 **특정 주파수에서만 크게 흔들린다.** 그 주파수가

$$f_c = \frac{1}{2\pi\sqrt{LC}}$$

### 2-3. 문제: 필요한 인덕터가 말도 안 되게 크다

166 Hz에서 공진시키려면 인덕터가 얼마나 필요할까? 실제 계산해보면:

| 채널 | 필요한 인덕터 L |
|---|---|
| ch0 (166 Hz) | **11.7 헨리** |
| ch15 (6761 Hz) | **0.21 헨리** |

11.7 H짜리 코일은 **주먹보다 크고 무겁다.** 스마트워치에 16개를 넣는 건 불가능하다.

### 2-4. 해결: GIC = "커패시터를 인덕터로 둔갑시키는 회로"

여기서 **GIC(Generalized Impedance Converter)** 가 등장한다. op-amp 2개와 저항 몇 개로
**커패시터가 인덕터처럼 보이게** 만든다.

```
        ┌─────────────────────┐
 신호 ──┤  op-amp 2개 + 저항   ├── 실제로는 커패시터가 들어있음
        │       (GIC)         │
        └─────────────────────┘
              ↑
        하지만 바깥에서 보면 "인덕터"처럼 동작!
```

왜 이게 가능할까? op-amp가 전류를 **한 박자 늦게/빠르게** 흘려주도록 조작하면, 바깥에서
보기엔 인덕터와 구분이 안 된다. (인덕터의 특징이 바로 "전류가 전압보다 늦게 따라옴"이다)

만들어지는 가짜 인덕터의 크기는:

$$\boxed{L = R_A^2 \times C}$$

**저항 제곱이 곱해지는 게 핵심이다.** RA = 12.34 kΩ이면 $R_A^2 = 1.5억$이라, 아주 작은
커패시터(76 nF)로도 11.7 H를 만들어낸다.

### 2-5. 그래서 이 필터의 성질 3가지

회로를 풀면 세 가지 공식이 나온다 (유도 과정은 생략하고 결과만):

| 성질 | 공식 | 의미 | 조절하는 부품 |
|---|---|---|---|
| **중심 주파수** | $f_c = \dfrac{1}{2\pi R_A C}$ | 어느 음정을 고를까 | **RA와 C** |
| **선택도 Q** | $Q = \dfrac{R_1}{R_A}$ | 얼마나 좁게 고를까 | **R1** |
| **이득** | **2배 (6 dB)** | 통과대역에서 2배 커짐 | (고정) |

**아주 편리한 성질**: `f_c`는 RA와 C가 정하고, `Q`는 R1이 정한다. 즉 **R1을 바꿔도 f_c는
그대로**다. 그래서 채널을 설계할 때 "먼저 RA로 주파수를 맞추고, 그다음 R1으로 폭을
조절"하면 된다.

**Q가 뭔지 감 잡기**: 다시 그네 비유로,
- R1이 크다 = 그네를 살짝만 건드림 = 자기 리듬대로 오래 흔들림 = **Q 큼 = 좁고 뾰족한 필터**
- R1이 작다 = 그네를 꽉 붙잡음 = 금방 멈춤 = **Q 작음 = 넓고 뭉툭한 필터**

### 2-6. 실측으로 확인

시뮬레이션에서 입력에 ±5 mV(10 mVpp) 신호를 넣었더니:

```
입력 v_in  : ±5.00 mV
출력 v_filt: ±10.01 mV     →  이득 = 2.00 ✅ (공식과 정확히 일치)
```

그리고 **DC(무음일 때)는 어떻게 되나?** 이게 중요하다:

| 입력 DC (vin) | 600 | 700 | 800 | 900 | 1000 mV |
|---|---|---|---|---|---|
| **출력 DC (v_filt)** | 890.0 | 890.0 | 890.0 | 890.0 | 890.0 mV |

> **v_filt의 DC는 입력과 전혀 상관없이 항상 890 mV다.**

왜? op-amp의 황금률로 풀 수 있다. 회로 안의 분압기와 가상 단락 조건을 연립하면
`v_filt = 0.9 V`가 나온다. **입력 DC가 뭐든 출력은 0.9 V에 고정**된다.

(실제로 890인 이유는 op-amp가 완벽하지 않아서 생기는 **10 mV의 오차**다. 뒤에서 다시 나온다.)

> 💡 **이건 고장 진단에도 쓴다**: `v_filt`가 `vin`을 따라가면 GIC가 고장 난 것이다.
> 실제로 이 방법으로 동료 회로의 U2 고장을 찾아냈다.

## 3. 2단: 능동 검출기 — "얼마나 센가"로 바꾸기

### 3-1. 왜 필요한가

필터를 통과한 신호는 **아직 위아래로 진동**한다. 우리가 알고 싶은 건 "이 대역에 지금
에너지가 있나?"이지, 진동 그 자체가 아니다.

```
v_filt:  ╭╮╭╮╭╮      ╭╮╭╮      ← 진동하는 신호
        ╯╰╯╰╯╰──────╯╰╯╰──

우리가 원하는 것:
        ╱‾‾‾╲___    ╱‾╲__      ← "지금 세다/약하다"의 윤곽 = 엔벨로프
```

**진동을 → 크기(엔벨로프)로 바꾸는 게 검출기의 일**이다. 두 단계로 한다:
1. **정류**: 아래로 가는 부분을 위로 접어 올림 (또는 한쪽만 취함)
2. **평활**: 커패시터로 뾰족한 부분을 뭉갬

### 3-2. 다이오드만으로는 왜 안 되나

정류는 보통 **다이오드**(한 방향으로만 전류를 통과시키는 부품)로 한다. 그런데 문제가 있다.

> 다이오드는 **0.3 V 정도 이상**이 걸려야 비로소 열린다. (문턱 전압)

우리 신호는 **겨우 10 mV**다. 0.3 V 문턱을 넘을 수가 없다. **다이오드가 아예 안 열린다.**

### 3-3. 해결: 다이오드를 op-amp "안"에 넣는다 (정밀 정류기)

```
        ┌──────── 피드백 경로 ────────┐
        │                            │
 입력 ──┤─\                          │
        │  \  op-amp  ──▶|── 출력 ───┤
   0.9V ┤+ /             다이오드
        └─/
```

op-amp는 황금률 1에 따라 **"− 입력을 + 입력과 같게" 만들려고 무슨 짓이든 한다.**
다이오드가 0.3 V를 먹으면? **op-amp가 출력을 0.3 V 더 밀어올려서 상쇄한다.**

즉 **바깥에서 보면 문턱이 사라진 완벽한 다이오드**처럼 동작한다. 이래서 "정밀(precision)
정류기"라 부르고, "능동(active)"이라는 이름이 붙었다.

### 3-4. 다이오드 두 개(D1, D2)의 역할 분담

우리 회로엔 다이오드가 2개 있다. 신호가 위로 갈 때와 아래로 갈 때 **번갈아 일한다**.

**신호가 아래로 내려갈 때 (v_filt < 0.9 V)**
- op-amp가 출력을 올림 → **D2가 열림** → 커패시터 C3를 **충전**
- 얼마나? 저항 비율만큼 증폭해서: **4.7배** (= R5/R4 = 47k/10k)

**신호가 위로 올라갈 때 (v_filt > 0.9 V)**
- op-amp가 출력을 내림 → **D1이 열리고 D2는 닫힘**
- C3는 op-amp에서 **분리**되어, R5를 통해 천천히 방전

> 즉 이 검출기는 **"아래로 내려가는 반쪽만" 골라서 크기를 재는 장치**다.

### 3-5. C3 — 빠르게 채우고 느리게 비운다

C3(100 nF)가 "기억"을 담당한다.

| | 경로 | 속도 |
|---|---|---|
| **충전** | op-amp가 D2를 통해 **능동적으로 밀어넣음** | **빠름** (0.65 ms) |
| **방전** | R5(47 kΩ)를 통해 **저절로 새나감** | **느림** (4.7 ms) |

방전 속도는 그 유명한 RC 시상수:

$$\tau = R_5 \times C_3 = 47{,}000 \times 100 \times 10^{-9} = 4.7\ \text{ms}$$

**약 7배 비대칭**이다. 이게 왜 좋을까?

```
        ╱|  ╱|  ╱|      ← 빠르게 올라가고 (소리 감지 즉시 반응)
       ╱ | ╱ | ╱ |
      ╱  |╱  |╱  ╲___   ← 천천히 내려옴 (진동 사이사이를 메워줌)
```

빠른 충전 = **소리가 시작되면 즉시 반응**.
느린 방전 = **진동의 골짜기마다 뚝뚝 끊기지 않고 이어짐**.

**왜 하필 4.7 ms인가?** 시간 규모를 비교해보면 납득이 된다:

| 시간 규모 | 값 |
|---|---|
| 소리 한 주기 (1 kHz) | 1 ms |
| **엔벨로프 τ** | **4.7 ms** |
| 음소 하나 (ㅅ, ㅏ 등) | 수십 ms |

**주기보다는 길고 음소보다는 짧다.** 그래서 진동은 뭉개주면서 "ㅅ"과 "ㅏ"는 구별한다.

### 3-6. 실측 결과

**입력-출력 관계 (DC 전달곡선)** — 직접 측정:

| v_filt | 860 | 880 | **890** | 895 | 900 | 910 mV |
|---|---|---|---|---|---|---|
| **v_env** | 1058.9 | 964.9 | **917.9** | 895.0 | 894.4 | 894.4 mV |

두 구간으로 나뉜다:
- **895 mV보다 아래**: 기울기 −4.70 (= −R5/R4) → 내려간 만큼 4.7배로 올라감
- **895 mV보다 위**: 894.4 mV로 **평평** → 정류가 꺼진 상태 (바닥)

**실제 파형** (10 mVpp를 166 Hz로 넣었을 때):

| 항목 | 값 |
|---|---|
| 무음일 때 v_env | 917.8 mV |
| 소리 있을 때 | 920.6 ~ 968.7 mV |
| **흔들림 폭(swing)** | **48.0 mV** |

## 4. 3단: 비교기 — 0/1로 만들기

가장 단순한 단이다.

```
        ┌─────────┐
v_env ──┤+        │
        │  비교기  ├── 0 V 또는 1.8 V
v_thr ──┤−        │
        └─────────┘
```

**v_env가 v_thr보다 크면 1.8 V(=1), 작으면 0 V(=0).** 그게 전부다.

기준 전압 `v_thr`은 1-1에서 배운 **분압기**로 만든다:

$$v_{thr} = 1.8 \times \frac{R_8}{R_7 + R_8}$$

이 0/1 신호가 디지털 쪽으로 넘어가고, 10 ms 단위로 묶으면 **[16채널 × 시간] 이진
이미지**가 된다. 그게 신경망의 입력이다.

> 💡 **왜 굳이 0/1로?** 아날로그 값을 그대로 쓰려면 ADC가 필요하고, ADC가 전력을 많이
> 먹는다. **0/1은 그냥 선 하나**면 되고, 신경망도 곱셈 대신 XNOR로 계산할 수 있어
> 훨씬 싸다.

## 5. 전체 흐름 한 장 요약

```
① 마이크        0.9 V 중심, ±5 mV로 흔들림 (10 mVpp)
      ↓
② GIC 필터      자기 대역만 통과, 2배 증폭
   v_filt       → 0.9 V(실제 890) 중심, ±10 mV로 흔들림
      ↓
③ 능동 검출기    아래쪽 반주기를 4.7배 정류 → C3에 저장
   v_env        → 894 mV(바닥)에서 위로 솟는 톱니 (최대 969 mV)
                   빠른 충전(0.65 ms) / 느린 방전(4.7 ms)
      ↓
④ 비교기        v_thr(분압기)과 비교
   v_comp       → 0 또는 1.8 V 펄스
      ↓
⑤ 디지털        10 ms 창으로 묶어 [16 × 128] 이진 이미지 → 신경망
```

**각 단이 답하는 질문**:

| 단 | 질문 | 답하는 방식 |
|---|---|---|
| GIC 필터 | "**어느** 주파수?" | 공진으로 자기 대역만 통과 |
| 능동 검출기 | "**얼마나** 세게, **얼마나** 오래?" | 정류 + C3 평활 |
| 비교기 | "**울렸다고 볼까?**" | 기준 전압과 비교 |

## 6. 지금 이 회로의 숙제 3가지

### 숙제 1: R7/R8 값이 잘못돼 있다 ← 즉시 고칠 것

무음일 때 v_env가 이미 **917.8 mV**인데, 지금 CSV의 기준 전압이 **910~924 mV**다.
13개 채널은 기준이 무음 상태보다 **낮아서**, **소리가 없어도 계속 1**이다. 정보가 0이다.

**고치는 법**: 기준을 무음값(917.8) **위로** 올린다.
$$v_{thr} = 917.8\ \text{mV} + (\text{여유})$$
자세한 표: [`../analog/AFE_tuning/artifacts/r7r8_per_channel.md`](../analog/AFE_tuning/artifacts/r7r8_per_channel.md)

### 숙제 2: 무음일 때 v_env가 894가 아니라 918인 이유 (오프셋)

이론상 무음이면 v_env가 바닥(894 mV)에 있어야 하는데 **918 mV**다. 24 mV나 높다. 왜?

op-amp가 완벽하지 않아서다. 실제 op-amp는 **입력 오프셋**이라는 작은 오차(수 mV)가 있다.

```
v_filt의 DC = 890 mV      ← GIC op-amp 오차 (−10 mV)
검출기 기준  = 895 mV      ← 검출기 op-amp 오차 (−5 mV)
        차이 = 5 mV  →  ×4.7배 증폭  →  +23 mV
```

**5 mV짜리 오차가 23 mV로 부풀려진다.** 그리고 이 오차는 **부품마다 다르다.** 그래서:
- 같은 R7/R8을 모든 기기에 쓸 수 없다
- **기기마다 한 번씩 측정해서 맞추는 캘리브레이션이 필요**하다

**대안**: 검출기 앞에 커패시터를 하나 넣어 **AC 결합**하면 DC 오차가 통과하지 못해
무음값이 항상 895 mV로 고정된다 (시뮬로 확인). 다만 커패시터 16개가 추가된다.

### 숙제 3: 신호가 너무 작다 (특히 고음)

같은 10 mVpp를 넣어도 채널마다 결과가 천지차이다:

| 채널 | swing |
|---|---|
| ch0 (166 Hz) | ~72 mV ✅ |
| ch8 (2 kHz) | ~33 mV ✅ |
| ch13 (4.9 kHz) | ~7 mV △ |
| **ch15 (6.8 kHz)** | **~1.2 mV** ❌ |

비교기 자체의 오차가 수 mV인데 **ch15의 신호가 1.2 mV**다. **오차가 신호보다 크다** =
그 채널은 동전 던지기와 같다.

게다가 이건 **가까이서 크게 말했을 때** 기준이다. 조금만 멀어져도(1 mVpp) 모든 채널이
무너진다.

**해결책**: 마이크 바로 뒤에 **증폭기(프리앰프)를 하나** 달아 신호를 10배로 키운다.
그러면 고음 채널도 20~58 mV가 되어 오차를 훌쩍 넘는다.

## 10. "v_env = 768 mV" 미스터리 (4채널 회로도 이미지)

동료의 4채널 회로도 PNG에는 무신호 v_env가 **768 mV**로 찍혀 있었다. 그런데 검증된
v15 단일채널 넷리스트(실제 벤더 모델)로 재현하면 **917.8 mV**다. 어느 쪽이 맞나?

실제 벤더 모델로 검출기를 3가지로 돌려봤다:

| 검출기 버전 | 정지 v_env |
|---|---|
| 정상 (v15 그대로) | 917.8 mV |
| 다이오드 뒤집기 | 895.6 mV |
| 뒤집기 + 게인 12배 | 896.6 mV |

**셋 다 894~918 mV.** 검출기 DC 전달곡선의 바닥이 894 mV이고 정지점이 918 mV라,
**768 mV는 이 회로가 만들 수 없는 값**이다(바닥보다 낮음).

**결론**: 768이 찍힌 4채널 회로도의 ENV 블록은 검증된 v15 단일채널 검출기와 **다른
회로**다(옛 버전이거나, 신호가 인가된 채 캡처됐거나, 다른 변형). 동료의 `VALIDATION_ko.md`가
실제 모델로 측정해 확정한 값은 **917.83 mV**이고 우리도 그대로 재현했으므로, **권위 있는
값은 918 mV**다. 768을 확정 설명하려면 `ENV_0.kicad_sch`(또는 그 넷리스트)가 필요하다.
