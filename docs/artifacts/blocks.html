RTL 블록 열두 개

비교기 16가닥이 클래스 인덱스 하나가 되기까지 Verilog 파일 열두 개를 지난다. 왼쪽에서 하나를 고르면 그 모듈의 포트·파라미터와, 무엇보다 왜 그렇게 생겼는지가 나온다. 설계 판단이 대부분 주석에 적혀 있어서 그걸 옮겼다.

계층은 인스턴스 관계다. 들여쓰기된 것은 위 모듈이 안에서 인스턴스화하는 모듈이고, 같은 모듈이 여러 자리에 나타난다 — kws_dw_conv 는 kws_tcs_sub 안에도 있고 kws_top 이 conv2_dw 로 직접 쓰기도 한다. folded 데이터패스라 같은 엔진을 시분할하기 때문이다 (CLAUDE.md §0).

반복되는 관용구 셋

모듈마다 포트가 비슷해 보이는 데는 이유가 있다. 층 모듈 넷은 포트 이름이 완전히 같고, 그래서 평면(kws_plane)이 어느 둘 사이에나 들어간다.

① push / real / flush 계약

kws_conv1·kws_block·kws_tcs_sub· kws_dw_conv 가 같은 포트를 쓴다:

start, in_push, in_real, in_frame busy, out_valid, out_frame

in_real=0 인 push 가 플러시다. depthwise 는 출력 t 를 내려면 입력 t+PAD 가 필요해서 PAD 만큼 앞서 달리고, 끝에서 그만큼 빈 push 로 뽑아내야 한다. 그 개수는 소비자의 성질이라 매니페스트에서 온다 — 평면 넷이 12·14·16·28 로 전부 다르다.

② 이진 내적 = 2·popcount(XNOR) − N

-1 → 비트 0 +1 → 비트 1 LSB 부터, 마지막 축을 따라 팩킹

kws_bin_mac 하나가 모든 이진 층의 밑바닥이다. 이 설계에 곱셈기는 없다. 벡터 길이가 32의 배수가 아니면 0으로 채워지는데 0 비트는 진짜 −1 이라 합에 기여한다 — 그래서 마스크를 호출자가 아니라 여기서 건다. 빼먹으면 "작고 그럴듯하고 데이터에 따라 달라지는 오차"가 나온다.

③ 평면 = 층 사이의 주차장

스트리밍은 층 안에서는 옳고 층 사이에서는 틀리다. 접합부마다 도착 시각을 손으로 맞춰야 하는데, kws_block 이 접합 하나 때문에 버그를 둘 냈다.

평면을 두면 "여섯 프레임 전"이 붙잡고 있을 것이 아니라 주소가 된다. 층 L 이 다 쓰고 나서 L+1 이 읽기 시작하므로 맞출 타이밍이 없다. 평면 넷, 합 20 Kbit.
